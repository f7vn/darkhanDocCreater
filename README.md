# Qūjat — генератор документов

На рабочем компьютере оперативная памятка по доступам, Railway и архитектуре хранится в `PROJECT_CONTEXT.md`. Она намеренно исключена из Git, поскольку содержит пароль.

Локальный сайт формирует два файла по выбранному виду закупки и площади. Для варианта «Декоративные работы + стенды» дополнительно указываются количество стендов и цена одного стенда у каждого поставщика:

1. редактируемую техническую спецификацию `.docx`;
2. единый `.pdf` из обоснования и трёх коммерческих предложений с исходными печатями и подписями.

После успешной сборки оба файла начинают скачиваться автоматически. Ссылки на них остаются на странице для повторного скачивания или на случай, если браузер ограничил множественные загрузки.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
DOCGEN_USERNAME=ваш_логин DOCGEN_PASSWORD=ваш_пароль .venv/bin/python app.py
```

Откройте <http://127.0.0.1:8765>.

Для преобразования обоснования в PDF нужен LibreOffice (`soffice`). На macOS также используется Arial; при его отсутствии подойдёт DejaVu Sans.

## Railway

Проект содержит `Dockerfile`, который устанавливает LibreOffice и необходимые шрифты. Railway автоматически обнаружит его при запуске `railway up`.

Приложение принимает порт из переменной `PORT` и на Railway слушает интерфейс `0.0.0.0`. Проверка готовности доступна по адресу `/health`.

Данные входа задаются переменными окружения:

- `DOCGEN_USERNAME` — логин;
- `DOCGEN_PASSWORD` — пароль.

## Данные и шаблоны

Исходные файлы находятся в `templates/`. Сформированные комплекты сохраняются в `generated/` и доступны только по уникальному адресу конкретной генерации.

Поддерживаются четыре варианта: эстетическое оформление, декоративно-отделочные работы, нанесение надписей и изображений, а также комбинированные декоративные работы со стендами. В комбинированном варианте площадь и количество стендов независимо подставляются в русскую и казахскую части технической спецификации, а стоимость стендов прибавляется к стоимости работ в каждом коммерческом предложении.
