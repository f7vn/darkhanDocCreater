# Qūjat — генератор документов

На рабочем компьютере оперативная памятка по доступам, Railway и архитектуре хранится в `PROJECT_CONTEXT.md`. Она намеренно исключена из Git, поскольку содержит пароль.

Сайт формирует два файла по выбранному виду закупки. Вводятся площадь и цена за м², количество и цена стенда либо оба набора значений для комбинированного варианта:

1. редактируемую техническую спецификацию `.docx`;
2. единый `.pdf` из обоснования и трёх коммерческих предложений с исходными печатями и подписями.

После успешной сборки оба файла начинают скачиваться автоматически. Ссылки на них остаются на странице для повторного скачивания или на случай, если браузер ограничил множественные загрузки.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
DOCGEN_USERNAME=ваш_логин DOCGEN_PASSWORD=ваш_пароль .venv/bin/python app.py
```

Откройте <http://127.0.0.1:8765>.

Для преобразования обоснования в PDF нужен LibreOffice (`soffice`). На macOS также используется Arial; при его отсутствии подойдёт DejaVu Sans.

## Railway

Проект содержит `Dockerfile`, который устанавливает LibreOffice и необходимые шрифты. Railway автоматически обнаружит его при запуске `railway up`.

Приложение принимает порт из переменной `PORT` и на Railway слушает интерфейс `0.0.0.0`. Проверка готовности доступна по адресу `/health`.

Данные входа задаются переменными окружения:

- `DOCGEN_USERNAME` — логин;
- `DOCGEN_PASSWORD` — пароль.

## Данные и шаблоны

Активные шаблоны находятся в пяти отдельных подпапках `templates/`. Реестр `templates/catalog.json` задаёт для каждого вида работ техспецификацию, обоснование и три КП в порядке «базовая цена, первая надбавка, вторая надбавка». Этот же реестр задаёт поставщиков в интерфейсе и ключи серверных расчётов — отдельного списка фирм в JavaScript нет.

Сформированные комплекты сохраняются в `generated/` и доступны только по уникальному адресу конкретной генерации.

Поддерживаются пять вариантов:

1. Эстетическое оформление.
2. Декоративно-отделочные работы.
3. Услуги по изготовлению стендов.
4. Нанесение надписей и изображений.
5. Декоративные работы + стенды.

Базовая цена редактируется во всех вариантах. Цены двух конкурентов рассчитываются автоматически с надбавками 7% и 15%; оба процента можно изменить. В комбинированном варианте надбавки применяются и к цене за м², и к цене стенда. Цены округляются до двух знаков после запятой, затем рассчитываются суммы.

Комплект на стенды использует отдельные шаблоны `templates/stands/` и поставщиков ИП Әбдіқұл, ТОО «Торговая сеть Казахстан» и ИП «Андрей и Ко». Количество подставляется в русскую и казахскую таблицы техспецификации; цены и суммы — в обоснование и все три КП.

Все 25 шаблонов взяты из соответствующих разделов папки «Для сайта 2». Исходные имена и папки записаны в `source_folder` и `source_files` реестра. Четыре обоснования в старом формате `.doc` однократно преобразованы в `.docx`; остальные файлы скопированы без изменений. Исходники в Downloads не редактируются. Старые файлы в корне `templates/` оставлены как архив, но не участвуют в генерации.

27 октября 2026 года девять КП обновлены PDF-оригиналами из папки «КП с подписями и печатями». Если у поставщика задан `signed_offer`, генератор использует именно этот PDF вместо прежнего `offer`. `signed_source` и `signed_sha256` фиксируют происхождение и контрольную сумму; копии `signed-*.pdf` хранятся в своей папке вида работ без изменения оригиналов. Остальные шесть КП, ТС и обоснования остаются из «Для сайта 2».

| Вариант | Обновлённые подписанные КП |
| --- | --- |
| Эстетическое оформление | Best Production, ИП Нәлібай |
| Декоративно-отделочные работы | ИП Абдыхалыков, ИП Сарсенова |
| Изготовление стендов | ИП Әбдіқұл |
| Нанесение надписей и изображений | Best Production, ИП Нәлібай |
| Декоративные работы + стенды | Best Production, ИП Нәлібай |

Подстановка идёт в проверенные поля PDF без перевёрстки подписей, печатей и реквизитов. В подписанных КП сохраняются исходные пиксели изображений и векторный текст; удаляются жёлтые поля и пустые служебные маркеры Apple Preview «SIGN», закрывается только серая полоса у левого края. Настоящие электронные подписи и неизвестные поля PDF не удаляются: генерация такого шаблона завершается ошибкой. Обновления импортирует `scripts/import_signed_offers.py /путь/к/папке`: сопоставляет все PDF по виду работ и имени поставщика, проверяет полноту и не перезаписывает отличающиеся файлы.

Текст техспецификаций берётся целиком из своего исходника, заменяются только объёмы в обеих языковых таблицах. Обоснования сохраняют исходную структуру; примерные суммы заменяются фактическими, добавляется расчёт каждого из трёх КП на обоих языках. В исходниках пунктов 1 и 4 обоснование одинаковое: для пункта 4 дополнительно исправляется название предмета закупки. Статические правовые формулировки и рыночные ссылки сохраняются из образцов; генератор не выполняет их юридическую проверку.

Для первичного импорта есть `scripts/import_templates.py`. Он принимает путь к папке с образцами и `--soffice /путь/к/soffice`, учитывает Unicode-имена и отказывается перезаписывать уже импортированные файлы.

Проверка расчётов:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Полная проверка генерации всех пяти комплектов, включая дробные значения:

```bash
.venv/bin/python scripts/check_packages.py
.venv/bin/python scripts/check_packages.py --large-prices
```

Проверка включает отдельные страницы подписанных КП: фактические суммы, отсутствие «SIGN» и полей формы, сохранность исходных пикселей подписей и печатей после объединения PDF.

Проверка опубликованного сайта: задайте `DOCGEN_USERNAME` и `DOCGEN_PASSWORD`, затем выполните:

```bash
.venv/bin/python scripts/check_packages.py --base-url https://qujat-docgen-production.up.railway.app
```

Для необязательной браузерной проверки нужен Node.js с Playwright: `node scripts/check_browser.cjs [адрес]`. Данные доступа берутся только из переменных окружения. При необходимости путь к Chromium задаётся через `PLAYWRIGHT_CHROMIUM_EXECUTABLE`. Проверяются все пять режимов на desktop/mobile, расчёты, доступные имена надбавок, отсутствие горизонтального скролла, восьмизначная цена и скачивание DOCX/PDF.
